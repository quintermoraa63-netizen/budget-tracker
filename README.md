# Personal Budget & Expense Tracker

## Description

The Personal Budget & Expense Tracker is a simple web project designed to help users keep track of their income and expenses. It provides a clear and simple interface for entering expense details.

## Features

* Add expense name, amount, and category
* View the expenses section
* Budget tips with an embedded YouTube video
* Expandable budgeting tips section
* Styled buttons and input fields
* Responsive and user-friendly design

## Technologies Used

* HTML
* CSS

## Project Files

* `index.html` — contains the structure and content of the webpage.
* `style.css` — contains the styling and design of the webpage.

## Learning Outcomes

Through this project, I gained practical experience in creating web pages using HTML and CSS. I also learned how to use forms, images, embedded videos, tables, CSS selectors, and interactive HTML elements such as details and summary.
