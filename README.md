# Personal Budget & Expense Tracker

## About the Project

This project is a simple Personal Budget & Expense Tracker created using HTML and CSS. It helps users view and organize their expenses in one place.

## What I Built

* A page heading and description for the Budget Tracker.
* An **Add Expense** form with fields for expense name, amount, category, and date.
* A **Budget Tips** section with a budgeting video and helpful information.
* An **Expenses Table** showing sample expenses with their name, amount, category, and date.
* A consistent color palette, typography, spacing, borders, and rounded corners using CSS.

## Technologies Used

* HTML5
* CSS3
* Google Fonts

## CSS Styling

The project uses CSS to create a consistent purple color theme, readable fonts, styled form inputs and buttons, alternating table row colors, and separate card-like sections using the CSS box model.

## Project Files

* `index.html` – Contains the structure and content of the Budget Tracker.
* `style.css` – Contains the colors, fonts, spacing, borders, and other visual styling.
* `README.md` – Explains the project and its main components.
